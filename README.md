# CareBridge static website

A responsive single-page marketing site for CareBridge. No application backend or patient information is collected.

## Preview locally
Open `index.html` in a browser (internet access required for Google Fonts).

## Publish to GitHub Pages
1. Create a **public** GitHub repository (for example, `carebridge`).
2. Upload `index.html`, `styles.css`, and `script.js` to the root of the `main` branch.
3. Open repository Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. Wait for GitHub to publish your site at `https://YOURUSERNAME.github.io/carebridge/`.
5. Optionally add a custom domain under Settings → Pages and configure DNS at your domain registrar.
